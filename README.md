# Data Cleaning & Preparation

This project was completed as part of the DecodeLabs Internship Program.

## Project Overview

The goal of this project was to clean and prepare a raw e-commerce sales dataset by identifying missing values, removing duplicate records, correcting data formats, and validating the final dataset before analysis.

## What I Did

- Identified missing or null values.
- Removed duplicate `OrderID` records.
- Standardized dates to `YYYY-MM-DD` format.
- Corrected text formatting and whitespace issues.
- Validated customer IDs, order dates, and price calculations.
- Documented and confirmed all quality checks passed.

## Tools Used

- Microsoft Excel
- Google Sheets
- Spreadsheet formulas for validation

## Project Deliverables

- `Project_1_Data_Cleaning_Report-1.pdf` — written report with cleaning and verification details.
- `Dataset for Data Analytics _Dataset_Cleaned Excel.xlsx` — final cleaned dataset.
- Supporting validation and screenshot files from the cleaning process.

## How to Review

1. Open the Excel file in Microsoft Excel or Google Sheets.
2. Review the cleaned dataset and validation tabs.
3. Check the formula-based quality checks and PASS results.
4. Open the PDF report for the written methodology and findings.

No code installation is required for this project because it was completed as an Excel-based data cleaning task.

## Result

The final dataset was validated successfully, with all documented checks marked as passing.
